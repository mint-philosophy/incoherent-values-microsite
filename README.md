# Incoherent Values? microsite

This directory contains the standalone static MINT research-story microsite for
“Incoherent Values? Probing LLM Preferences Through Parametric Variation.”

It is ready to serve from a GitHub Pages repository root without a build step.
All local styles, scripts, and image references are relative to `index.html`.
The MINT banner and shared navigation are loaded from `mintresearch.org`.

## Local preview

From this directory:

```powershell
py -m http.server 8010
```

Then visit:

```text
http://localhost:8010/
```

## GitHub Pages

If this directory becomes the repository root, configure GitHub Pages to deploy
from the repository root. The entry point is `index.html`.

No GitHub push or Pages deployment has been performed from this workspace.

## Publication status

This remains a review prototype. Several visible results are explicitly marked
as illustrative dummy data or placeholders and must be replaced with verified,
publication-approved results before treating the site as final research
communication.

The arXiv, PDF, dataset, and code links match the publication-approved canonical
targets used by the instantiated Incoherent Values microsite.
