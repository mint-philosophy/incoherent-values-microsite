Models should be coherent

To trust Large Language Models, we need to know how they will perform in novel situations. Do they exhibit coherent values that will guide them?
We present a new way of testing LLM value coherence.

We gave LLMs many forced choices between two options to test for value (in)coherence.

Suppose that A is preferable to B. If A+ has even more of what makes A choiceworthy, then A+ should also be preferable to B.

If not, your values are incoherent. Here, they would be circular: A+>A>B>A+...

02

Create a Value Ladder.

For each of 100 options, we varied the parameter that makes it more or less choiceworthy. This meant that each option (T4) was paired with three progressively worse options (T1-T3), and three progressively better ones (T5-7). These were our 'value ladders'.

Their ranking should be monotonic (not decrease).

We compare the tiers on these value ladders to fixed alternatives to test if the model's values stay coherent.

We tested each pairing N times, in each order.

If the model's values are coherent, then as we "climb the ladder" its chance of picking the ladder option should grow monotonically (not decrease).
